### 👨‍💻 About Me

- 🏢 I work as a **Software Engineer** at **[Namirial Group](https://www.namirial.com)** — mostly backend
- 🐍 **Python** is my main language — I build async, high-performance backend systems
- 🌐 I'm comfortable across the stack: Vue on the frontend, and I work with Node.js and Go when a project calls for it
- 🧠 Working with LLMs and AI-assisted tooling — integrating them into real backend systems, not just prototypes
- 🏗️ I care about software architecture and system design as much as the code itself — scalable, maintainable systems over quick hacks
- 🛠️ Creator & maintainer of **[django-ninja-aio-crud](https://github.com/caspel26/django-ninja-aio-crud)** — an async CRUD framework built on top of Django Ninja
- 📈 Big believer in clean architecture, test-driven development, and squeezing out performance regressions before they ship
- 📫 Reach me at **peppe.c0126@gmail.com**
